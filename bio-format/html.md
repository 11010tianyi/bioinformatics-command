HTML
===

常用于可视化 QC 和分析报告的网页格式。Web document format commonly used for visual QC and analysis reports.

## 常见用途 | Common Uses

- FastQC、fastp、MultiQC 报告。
- pipeline summary report。
- 浏览器中直接查看交互或静态结果。

## 关键点 | Notes

- HTML 报告适合人工检查，不一定适合程序解析。
- 结构化数据通常另存 JSON/TSV。
- 归档时建议保留同名数据目录或附属文件。
