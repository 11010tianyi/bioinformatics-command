JSON
===

常用于工具报告、参数和结构化结果交换的轻量数据格式。Lightweight structured data format for reports, parameters, and result exchange.

## 常见用途 | Common Uses

- fastp JSON 报告。
- MultiQC 数据导出。
- workflow 参数或 API payload。

## 关键点 | Notes

- 适合程序读取，通常不适合手工大规模编辑。
- 字段名和层级由具体工具定义。
- 建议配合 schema 或示例文件管理。
